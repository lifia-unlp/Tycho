# Tycho Add-on

**Tycho Add-on** is a web browser extension that allows a person to participate in a usability test (experiment) designed and configured using the Tycho tool. The participant assumes a specific role within the test by executing a sequence of tasks defined by a protocol.


## Notes
To receive messages from another extension we use: `chrome.runtime.onMessageExternal.addListener()` as explained here https://developer.chrome.com/extensions/messaging
